# Third-party source

`vendor/skills-for-fabric` is an unmodified snapshot of the `skills/`, `common/`, README and LICENSE files from [microsoft/skills-for-fabric](https://github.com/microsoft/skills-for-fabric), commit `6c11ad58c25992e5d1435ce7cd80d217d5598a31`. Microsoft licenses this source under MIT; its original LICENSE is preserved in that directory. `skills.lock.json` records every shipped file's SHA-256 and the downloaded archive hash.

This project is a separate demo and is not a Microsoft-supported product. Upstream instructions inform the bounded tools; they do not confer cloud permissions. Vendored updates must come through a reviewed PR that updates the snapshot and lock together.
